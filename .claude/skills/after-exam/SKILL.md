# after-exam：考完之後（登記成績 → 錯題回鍋）

錯的題目才是分數來源。這個 skill 做兩件事：**把成績記下來**（家長頁畫走勢），
**把錯的概念換題再考一次**（首頁與家長頁出現「錯題回鍋」入口）。

## 輸入
- 哪一場考試（日期／科目／名稱，對照 `src/content/exams.ts` 找到那一筆；沒有就先照 `add-exam` 補一筆）。
- 分數（或等第）。
- 錯題：考卷照片、或媽媽口述「錯了哪幾題／哪個觀念」。沒有錯題也可以只登記分數。

## 步驟
1. **登記成績**：在該筆 `Exam` 加 `result`：
   ```ts
   result: {
     score: 86, total: 100,           // 段考／小考；模擬考用 grade: "A"
     weak: ["目鏡與物鏡的倍率相乘", "粗調節輪先於細調節輪"],   // 一句一個概念，寫「概念」不是題號
     note: "粗心 2 題、真的不會 1 題",  // 可省略
     mistakesQuizId: "quiz-science-microscope-mistakes-1",    // 有做錯題題組才填
   },
   ```
2. **錯題回鍋（有錯題時）**：照 `add-quiz` 出一組題組，檔名 `src/content/quizzes/<subject>-<topic>-mistakes-<n>.ts`，
   `id` 用 `quiz-<subject>-<topic>-mistakes-<n>`，掛同一個 `topicId`。
   - **不要抄考卷原題。** 每個錯的概念出 2～3 題「同概念、換情境／換問法」的變形題；
     干擾選項對準他這次犯的錯。
   - `concept` 直接用 `weak` 裡的那句，家長頁才能對起來。
   - `description` 寫明「X 月 X 日 XX 考的錯題回鍋」。
3. 若錯的概念在某個複習頁沒有卡，順手在該 `prep` 補 1～2 張卡（`add-prep` 的規則）。
4. `npm run check` 綠燈 → commit（訊息：`登記 9/10 自然小考 86 分＋錯題回鍋`）→ push。

## 語氣提醒
分數只是訊號；`note` 寫給媽媽看的觀察，不寫評價。錯題題組的 `explanation` 要說「為什麼」，
結尾可以加一句「上次你在這裡選了 X，因為……」，讓他看見自己的思路哪裡歪了。
